GPU VALIDATION SCOPE
--------------------
The Windows executable contains a real runtime-loaded OpenCL GPU path:
- OpenCL.dll discovery
- GPU device discovery
- context/queue/program/kernel creation
- BVH/primitive/material buffer upload
- row-chunk kernel dispatch
- progressive readback
- ray-count readback
- CPU fallback on OpenCL failure

This container exposes an OpenCL loader but no usable physical OpenCL platform/device, so the OpenCL backend could
not be run end-to-end on GPU hardware here. Kernel syntax and Windows compilation were validated instead.
