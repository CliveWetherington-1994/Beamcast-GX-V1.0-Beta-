Hardware limitation
-------------------
This environment does not expose a usable physical OpenCL GPU. The Win32 OpenCL host path cross-builds and the embedded kernel passes OpenCL 1.2 syntax validation, but end-to-end GPU performance must be measured on the destination machine with an actual OpenCL-capable GPU/driver.

Scope note
----------
No claim of "best optimization in the world" is made. Such a claim would require reproducible benchmarking against established production renderers across multiple CPUs, GPUs, scenes, quality targets, drivers, memory budgets, and power constraints.
